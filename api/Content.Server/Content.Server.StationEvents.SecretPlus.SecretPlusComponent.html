Class SecretPlusComponent

Basic metric-based event scheduler. Maintains a "chaos score", which is a number used to pick what events are rolled. Events are weighted by their normal weight and by roughly how close they are to (the negative of) the current chaos score. Chaos is passively generated by players, degenerated by ghosts, and changed by fired events' chaos scores. For more information, see the summaries of the fields.
